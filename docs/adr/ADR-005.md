ADR-005.md

SubmittalPackage is a new grouping entity, sourced from the Enterprise
Fidelity Review, not present in The Reference Engineering System.md's
literal entity list.

Reason:

The Fidelity Review documents an explicit parent/child relationship
("Submittal → Submittal Package") as a MUST-HAVE, matching real Procore
behavior of grouping related submittal items into one review cycle. The
frozen Reference Engineering System.md entity list does not name a Package
concept.

Implementation: `submittal_packages` is a first-class table
(project_id, name, description), and `submittals.package_id` is a nullable
foreign key to it. RES-3's own canonical seed data (Canonical_Demo_Dataset.md
§7) instantiates zero packages — SUB-118 is a single-item submittal with
package_id = NULL. The entity exists and is fully functional so a future
multi-item submittal scenario does not require a schema change, but nothing
in RES-3 requires a package to actually exist.
